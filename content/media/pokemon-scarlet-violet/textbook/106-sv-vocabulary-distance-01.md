# Parole per leggere Paldea — uno

A Paldea una conversazione può passare dalla scuola alla lotta, da un ricordo a
un'azione concreta. Le parole compaiono in situazioni diverse, ma ciascuna
conserva un valore preciso nella frase.

## Frasi ed uso

### [{{挨拶|あいさつ}}](term:term-sv-vocabulary-058-aisatsu) — saluto; saluti; formula di saluto

:::example_sentence
jp: >-
  なーんて{{挨拶|あいさつ}}の{{言葉|ことば}}もところ{{変|か}}わればグッモーニン！
translation_it: >-
  Beh, a seconda del posto, il saluto diventa “Buongiorno”!
:::

**Uso:** Nel contesto indica «saluto; saluti; formula di saluto».

### [{{着|き}}る](term:term-sv-vocabulary-242-kiru) — indossare; mettersi un capo

:::example_sentence
jp: >-
  アカデミーの{{制服|せいふく}}を{{着|き}}る。
translation_it: >-
  Indosso l'uniforme dell'Accademia.
:::

**Uso:** L'azione espressa nel contesto è «indossare; mettersi un capo».

### [{{不登校|ふとうこう}}](term:term-sv-vocabulary-363-futoukou) — assenteismo scolastico; mancata frequenza scolastica

:::example_sentence
jp: >-
  このまま{{不登校|ふとうこう}}が{{続|つづ}}けばシュウメイ{{殿|どの}}は{{退学|たいがく}}{{処分|しょぶん}}なんでしょ？
translation_it: >-
  Se continua a non frequentare la scuola, Shūmei verrà espulso, vero?
:::

**Uso:** Nel contesto indica «assenteismo scolastico; mancata frequenza scolastica».

### [{{抜|ぬ}}く](term:term-sv-vocabulary-203-nuku) — estrarre; tirare fuori; sradicare

:::example_sentence
jp: >-
  {{杭|くい}}を{{全部|ぜんぶ}}{{抜|ぬ}}くと、{{何|なに}}かが{{起|お}}こる。
translation_it: >-
  Quando estrai tutti i pali, succede qualcosa.
:::

**Uso:** L'azione espressa nel contesto è «estrarre; tirare fuori; sradicare».

### [{{面倒|めんどう}}](term:term-sv-vocabulary-315-mendou) — cura o assistenza; fastidio; problema

:::example_sentence
jp: >-
  だからボクが{{掟|おきて}}とか{{向|む}}いてるはずがないんだよでもさ{{団員|だんいん}}の{{面倒|めんどう}}{{見|み}}てるのってだいたいピーニャじゃん？
translation_it: >-
  Ecco perché non potrei mai essere adatto alle regole. Ma, dai, chi si prende cura dei membri del gruppo di solito è Pinya, no?
:::

**Uso:** Nel contesto indica «cura o assistenza; fastidio; problema».

### [ヒマ](term:term-sv-vocabulary-213-hima) — tempo libero; essere libero; non essere occupato

:::example_sentence
jp: >-
  {{今日|きょう}}はヒマだから、{{町|まち}}を{{歩|ある}}いてみよう。
translation_it: >-
  Oggi sono libero, quindi facciamo un giro in città.
:::

**Uso:** Nel dialogo aggiunge il valore di «tempo libero; essere libero; non essere occupato».

### [{{頂点|ちょうてん}}](term:term-sv-vocabulary-321-chouten) — vertice; apice; cima (ad es. di una montagna)

:::example_sentence
jp: >-
  この{{人|ひと}}はねーみんながあこがれるチャンピオンランクのさらに{{頂点|ちょうてん}}。
translation_it: >-
  Questa persona, beh… è il vertice assoluto del rango di Campione, quello a cui tutti aspirano.
:::

**Uso:** Nel contesto indica «vertice; apice; cima (ad es. di una montagna)».

### [いずれ](term:term-sv-vocabulary-223-izure) — prima o poi; un giorno; in futuro
