# Parole per leggere Paldea — ventitré

A Paldea una conversazione può passare dalla scuola alla lotta, da un ricordo a
un'azione concreta. Le parole compaiono in situazioni diverse, ma ciascuna
conserva un valore preciso nella frase.

## Frasi ed uso

### [{{記|き}}](term:term-sv-vocabulary-396-ki) — cronaca; annotazione; resoconto

:::example_sentence
jp: >-
  これは{{昔|むかし}}の{{探検|たんけん}}{{記|き}}だ。
translation_it: >-
  Questo è il resoconto di un'antica esplorazione.
:::

**Uso:** Nel contesto indica «cronaca; annotazione; resoconto».

### [{{寄|よ}}る](term:term-sv-vocabulary-150-yoru) — avvicinarsi; essere vicino a; radunarsi (in un unico luogo)

:::example_sentence
jp: >-
  でんきに{{弱|よわ}}いの{{寄|よ}}っといでー！
translation_it: >-
  Se sei sensibile all’elettricità, vieni qui!
:::

**Uso:** L'azione espressa nel contesto è «avvicinarsi; essere vicino a; radunarsi (in un unico luogo)».

### [{{台座|だいざ}}](term:term-sv-vocabulary-264-daiza) — piedistallo

**Uso:** Nel contesto indica «piedistallo».

### [{{休|やす}}める](term:term-sv-vocabulary-300-yasumeru) — poter riposare; riuscire a prendersi una pausa

### [っていうか](term:term-sv-vocabulary-109-tteiuka) — o meglio (direi); o più propriamente (direi); o forse dovrei dire

**Uso:** Nel dialogo aggiunge il valore di «o meglio (direi); o più propriamente (direi); o forse dovrei dire».
