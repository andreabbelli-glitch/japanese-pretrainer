# Using な-adjectives to describe verbs

## Formazione

Un aggettivo in な diventa avverbiale aggiungendo に alla radice: 下手 → 下手に, 静か → 静かに, きれい → きれいに.

:::example_sentence
jp: >-
  {{図書館|としょかん}}で{{静|しず}}かに{{小説|しょうせつ}}を{{読|よ}}む。
translation_it: >-
  Leggo un romanzo in silenzio in biblioteca.
:::

静かに descrive il modo di leggere anche se 小説を si trova in mezzo. Il modificatore non deve essere immediatamente adiacente al verbo.

## Confronto

静かな図書館 usa な perché modifica un nome; 静かに読む usa に perché modifica un verbo. Qui に forma un'espressione avverbiale di modo; la destinazione appartiene a un altro uso della particella.
