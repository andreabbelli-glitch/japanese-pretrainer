# 「も」(3) Emphasize something

## Quantità notevole

Dopo un nome o contatore, も segnala che il valore è sorprendente: in affermativo «addirittura / ben», con negazione «neanche».

:::example_sentence
jp: >-
  ビールを{{十本|じゅっぽん}}も{{飲|の}}んだ。
translation_it: >-
  Ha bevuto addirittura dieci birre.
:::

一本も飲まなかった significa invece «non ne ha bevuta neanche una».

## Verbo + も + しない

La base verbale può essere focalizzata: 見もしない, «non guarda nemmeno». も presenta perfino la soglia minima del guardare come sorprendentemente assente.
