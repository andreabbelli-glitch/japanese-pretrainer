# 「かな」You can start wondering

## Pensiero ad alta voce

かな si aggiunge alla fine di una frase piana e comunica curiosità, dubbio o riflessione: «chissà», «mi domando se…». Non richiede necessariamente una risposta dell'interlocutore.

:::example_sentence
jp: >-
  {{明日|あした}}は{{晴|は}}れるかな。
translation_it: >-
  Chissà se domani farà bel tempo.
:::

Può seguire verbi, aggettivi e nomi, anche al passato. È informale; la tradizione lo associa più alla voce maschile, ma nell'uso contemporaneo è comune anche tra donne.
