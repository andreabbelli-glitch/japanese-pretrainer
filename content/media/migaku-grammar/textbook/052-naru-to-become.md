# 「なる」The state or condition changes

## Formazione

なる descrive il passaggio a un nuovo stato.

- aggettivo in い: radice + くなる — 新しい → 新しくなる
- aggettivo in な: + になる — 元気 → 元気になる
- nome: + になる — 先生 → 先生になる

:::example_sentence
jp: >-
  {{子供|こども}}は{{静|しず}}かになる。
translation_it: >-
  I bambini diventano tranquilli.
:::

いい segue la radice よ- e forma よくなる, mai *いくなる.

## Sfumatura

なる è intransitivo: mette a fuoco il cambiamento del soggetto, non una persona che lo provoca. Il contesto decide se tradurre «diventa», «diventerà» o «sta diventando».
