# 「に」(3) Mark an indirect object

## Bersaglio dell'azione

に segue la persona o cosa verso cui è diretta un'azione. Con verbi di trasferimento o comunicazione può indicare destinatario, beneficiario o bersaglio; in italiano diventa spesso «a» o «per».

:::example_sentence
jp: >-
  {{先生|せんせい}}が{{娘|むすめ}}に{{日本語|にほんご}}を{{教|おし}}える。
translation_it: >-
  L'insegnante insegna giapponese a mia figlia.
:::

娘に è il ricevente dell'insegnamento; 日本語を è il contenuto direttamente coinvolto. Altri verbi frequenti sono 話す, 見せる, 投げる, 電話する e あげる.

## Tema e contrasto

Con は si forma には: 社長には酒を買う può significare «per il presidente, invece, comprerò del sakè», contrapponendo quel destinatario ad altri.
