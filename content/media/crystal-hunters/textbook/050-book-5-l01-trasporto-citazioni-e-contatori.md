# Trasporto, limiti e contatori

Nel Book 5 i personaggi trasportano oggetti, chiedono favori, contano cose,
insultano e riportano battute. Piccoli segnali come [だけ](term:term-ch-b5-dake),
[お{{願|ねが}}い](term:term-ch-b5-oi-8) e [{{一|ひと}}つ](term:term-ch-b5-tsu-6)
decidono il limite, il tono e la quantità della frase.

## Termini chiave

- [だけ](term:term-ch-b5-dake) - solo; soltanto
- [{{運|はこ}}ぶ](term:term-ch-b5-bu-1) - trasportare; portare
- [{{言|い}}う](term:term-ch-b5-u-2) - dire
- [また](term:term-ch-b5-mata-3) - di nuovo; ancora
- [{{馬鹿|ばか}}](term:term-ch-b5-entry-4) - stupido; idiota
- [{{一|ひと}}つ](term:term-ch-b5-tsu-6) - una cosa
- [{{二|ふた}}つ](term:term-ch-b5-tsu-7) - due cose
- [お{{願|ねが}}い](term:term-ch-b5-oi-8) - favore; richiesta; per favore
- [{{卵|たまご}}](term:term-ch-b5-entry-9) - uovo

## Pattern grammaticali chiave

- [verbi in ぶ: んだ／んで](grammar:grammar-ch-b5-verbi-in-1) - {{運|はこ}}ぶ -> {{運|はこ}}んだ／{{運|はこ}}んで
- [verbi in す: した／して](grammar:grammar-ch-b5-su-past-te) - {{倒|たお}}す -> {{倒|たお}}した／{{倒|たお}}して
- [{{一|ひと}}つ／{{二|ふた}}つ + の + N](grammar:grammar-ch-b5-n-5) - contatori generici con の davanti al nome

## 1. `だけ` e `お願い`: limite e richiesta

[だけ](term:term-ch-b5-dake) restringe il blocco che lo precede. Se lo vedi
dopo una quantità, quella quantità diventa il limite della frase.

:::example_sentence
jp: >-
  {{一|ひと}}つだけ。
translation_it: >-
  Solo uno.
:::

#### 🗺️ Anatomia della frase

*   `{{一|ひと}}つ` -> **Quantità**: una cosa.
*   `だけ` -> **Limite**: non due, non molte; solo quella.

[お{{願|ねが}}い](term:term-ch-b5-oi-8) è un nome, quindi può essere "una
richiesta" o "un favore", non solo la formula "per favore".

:::example_sentence
jp: >-
  {{一|ひと}}つだけお{{願|ねが}}いがある。
translation_it: >-
  Ho solo una richiesta.
:::

#### 🗺️ Anatomia della frase

*   `{{一|ひと}}つだけ` -> **Limite della quantità**.
*   `お{{願|ねが}}いが` -> **Cosa presente**: una richiesta entra nella frase con `が`.
*   `ある` -> **Esistenza inanimata**.

#### ⚖️ Contrasto operativo

[ください](term:term-ch-b4-kudasai-3) chiede direttamente un oggetto o
un'azione. [お{{願|ねが}}い](term:term-ch-b5-oi-8) può nominare il favore stesso.
Per questo `お{{願|ねが}}いがある` non significa "per favore c'è": significa
"ho una richiesta".

## 2. Trasportare e coniugare verbi in ぶ / す

[{{運|はこ}}ぶ](term:term-ch-b5-bu-1) porta una cosa da un punto a un altro.
Quando l'oggetto è concreto, come [{{卵|たまご}}](term:term-ch-b5-entry-9), il
blocco con `を` resta facile da vedere.

:::example_sentence
jp: >-
  {{卵|たまご}}を{{運|はこ}}ぶ。
translation_it: >-
  Trasporto l'uovo.
:::

#### 🗺️ Anatomia della frase

*   `{{卵|たまご}}を` -> **Oggetto trasportato**.
*   `{{運|はこ}}ぶ` -> **Azione fisica**: portare da un punto a un altro.

Con [verbi in ぶ: んだ／んで](grammar:grammar-ch-b5-verbi-in-1), passato e forma
in て cambiano suono.

:::example_sentence
jp: >-
  {{卵|たまご}}を{{運|はこ}}んだ。
translation_it: >-
  Ho trasportato l'uovo.
:::

:::example_sentence
jp: >-
  {{卵|たまご}}を{{運|はこ}}んで。
translation_it: >-
  Trasporta l'uovo.
:::

#### 🗺️ Anatomia della frase

*   `{{運|はこ}}ぶ` -> **Forma base**.
*   `{{運|はこ}}んだ` -> **Passato**: ぶ diventa んだ.
*   `{{運|はこ}}んで` -> **Forma in て**: ぶ diventa んで.

I [verbi in す: した／して](grammar:grammar-ch-b5-su-past-te) fanno un cambio
diverso.

:::example_sentence
jp: >-
  {{怪物|かいぶつ}}を{{倒|たお}}した。
translation_it: >-
  Ho sconfitto il mostro.
:::

:::example_sentence
jp: >-
  {{怪物|かいぶつ}}を{{倒|たお}}して。
translation_it: >-
  Sconfiggi il mostro.
:::

#### ⚖️ Contrasto operativo

Non cercare una regola unica per tutte le finali godan: `ぶ` porta a んだ／んで,
mentre `す` porta a した／して. Le forme sembrano piccole, ma in manga decidono
se l'azione è già avvenuta o se continua nella frase successiva.

## 3. Dire e riportare una battuta

[{{言|い}}う](term:term-ch-b5-u-2) è il verbo che ti permette di leggere frasi
riportate. Il contenuto può stare tra virgolette giapponesi `「...」` e prendere
`と` prima del verbo.

:::example_sentence
jp: >-
  カルが「{{行|い}}く」と{{言|い}}う。
translation_it: >-
  Kal dice: "Vado".
:::

#### 🗺️ Anatomia della frase

*   `カルが` -> **Chi parla**.
*   `「{{行|い}}く」` -> **Contenuto detto**.
*   `と` -> **Cornice di citazione**: marca ciò che viene riportato.
*   `{{言|い}}う` -> **Dire**.

[また](term:term-ch-b5-mata-3) può entrare in questo tipo di dialogo per
riaprire un'azione.

:::example_sentence
jp: >-
  また{{来|く}}る。
translation_it: >-
  Torno di nuovo.
:::

## 4. Contatori generici e parole urlate

[{{一|ひと}}つ](term:term-ch-b5-tsu-6) e [{{二|ふた}}つ](term:term-ch-b5-tsu-7)
sono contatori generici. Prima di un nome, si collegano con の.

:::example_sentence
jp: >-
  {{一|ひと}}つの{{卵|たまご}}。
translation_it: >-
  Un uovo.
:::

:::example_sentence
jp: >-
  {{二|ふた}}つの{{卵|たまご}}。
translation_it: >-
  Due uova.
:::

#### 🗺️ Anatomia della frase

*   `{{一|ひと}}つ` / `{{二|ふた}}つ` -> **Quantità generica**.
*   `の` -> **Collegamento al nome**.
*   `{{卵|たまご}}` -> **Cosa contata**.

[{{馬鹿|ばか}}](term:term-ch-b5-entry-4) è invece una parola di tono. Può essere
scritta in kanji, hiragana o katakana; la scelta grafica può rendere la battuta
più calma, più infantile o più urlata.

:::example_sentence
jp: >-
  {{馬鹿|ばか}}なことだ。
translation_it: >-
  È una cosa stupida.
:::

:::example_sentence
jp: >-
  バカ！
translation_it: >-
  Idiota!
:::

## Nota finale

In questa parte, le parole piccole cambiano la lettura più di quanto sembri:
だけ restringe, お{{願|ねが}}い nomina una richiesta, と incornicia ciò che viene
detto, つ conta oggetti. Dopo aver trovato questi segnali, lascia che il verbo
finale dica se la scena trasporta, dice, conta o giudica.
