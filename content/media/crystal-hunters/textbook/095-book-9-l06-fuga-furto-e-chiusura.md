# Fuga, furto e salti

Il finale del Book 9 stringe molte azioni: rubare, eliminare, accettare
un'offerta, trasportare qualcuno, nascere in una nuova condizione, evadere e
saltare giù. Sono verbi molto leggibili se segui bene `を`, `に`, `から` e il
verbo finale.

## Termini chiave

- [{{盗|ぬす}}む](term:term-ch-b9-nusumu) — rubare
- [{{始末|しまつ}}する](term:term-ch-b9-shimatsu-suru) — sistemare / eliminare
- [あの{{世|よ}}](term:term-ch-b9-anoyo) — l'altro mondo
- [{{懺悔|ざんげ}}](term:term-ch-b9-zange) — confessione, pentimento
- [{{手持|ても}}ち](term:term-ch-b9-temochi) — ciò che si ha con sé
- [{{奢|おご}}り](term:term-ch-b9-ogori) — offerta, pago io
- [{{脱走|だっそう}}](term:term-ch-b9-dassou) — fuga, evasione
- [{{飛|と}}び{{降|お}}りる](term:term-ch-b9-tobioriru) — saltare giù
- [{{何|なん}}とか](term:term-ch-b9-nantoka) — in qualche modo
- [また{{明日|あした}}](term:term-ch-b9-mata-ashita) — a domani

---

## 1. Rubare, minacciare, pentirsi

[{{盗|ぬす}}む](term:term-ch-b9-nusumu) è diretto: ciò che viene rubato prende
`を`.

:::example_sentence
jp: >-
  {{金|かね}}を{{盗|ぬす}}むな。
translation_it: >-
  Non rubare il denaro.
:::

[{{始末|しまつ}}する](term:term-ch-b9-shimatsu-suru) è più ambiguo. Può
essere "sistemare una faccenda", ma in una minaccia può diventare "eliminare".

:::example_sentence
jp: >-
  {{奴|やつ}}を{{始末|しまつ}}する。
translation_it: >-
  Sistemo quel tipo / lo elimino.
:::

Con [あの{{世|よ}}](term:term-ch-b9-anoyo) e [{{懺悔|ざんげ}}](term:term-ch-b9-zange),
la frase diventa apertamente mortale.

:::example_sentence
jp: >-
  あの{{世|よ}}で{{懺悔|ざんげ}}しろ。
translation_it: >-
  Pentiti nell'altro mondo.
:::

#### 🗺️ Anatomia della frase

*   `あの{{世|よ}}で` ➔ **Luogo estremo**: nell'aldilà.
*   `{{懺悔|ざんげ}}しろ` ➔ **Ordine duro**: pentiti/confessa.

## 2. Obiettivi e offerte

{{狙|ねら}}う può puntare un bersaglio o un premio.

:::example_sentence
jp: >-
  {{景品|けいひん}}を{{狙|ねら}}う。
translation_it: >-
  Punto al premio.
:::

[{{手持|ても}}ち](term:term-ch-b9-temochi) è ciò che si ha con sé adesso.

:::example_sentence
jp: >-
  {{手持|ても}}ちの{{金|かね}}がない。
translation_it: >-
  Non ho denaro con me.
:::

Se qualcuno paga, [{{奢|おご}}り](term:term-ch-b9-ogori) è
"offro io".

:::example_sentence
jp: >-
  {{今日|きょう}}は{{俺|おれ}}の{{奢|おご}}りだ。
translation_it: >-
  Oggi offro io.
:::

お{{言葉|ことば}}に{{甘|あま}}えて è una
formula di accettazione: prendo sul serio la sua gentile offerta.

:::example_sentence
jp: >-
  では、お{{言葉|ことば}}に{{甘|あま}}えて。
translation_it: >-
  Allora accetto volentieri la sua offerta.
:::

## 3. Portare, nascere, evadere

{{運|はこ}}ぶ è trasportare qualcuno o qualcosa da un
luogo all'altro.

:::example_sentence
jp: >-
  {{二人|ふたり}}を{{部屋|へや}}へ{{運|はこ}}ぶ。
translation_it: >-
  Trasporto le due persone nella stanza.
:::

#### 🗺️ Anatomia della frase

*   `{{二人|ふたり}}を` ➔ **Persone trasportate**.
*   `{{部屋|へや}}へ` ➔ **Direzione**.
*   `{{運|はこ}}ぶ` ➔ **Trasporto**.

{{生|う}}まれる può essere nascita concreta o inizio
di una nuova situazione.

:::example_sentence
jp: >-
  {{赤|あか}}ちゃんが{{生|う}}まれる。
translation_it: >-
  Nasce un bambino.
:::

[{{脱走|だっそう}}](term:term-ch-b9-dassou) è fuga da controllo o prigionia.

:::example_sentence
jp: >-
  {{奴隷|どれい}}たちが{{脱走|だっそう}}する。
translation_it: >-
  Gli schiavi evadono.
:::

## 4. Scendere o saltare giù

{{降|お}}りる è scendere. Con una nave o un veicolo,
`を` marca il punto da cui si scende.

:::example_sentence
jp: >-
  {{船|ふね}}を{{降|お}}りる。
translation_it: >-
  Scendo dalla nave.
:::

[{{飛|と}}び{{降|お}}りる](term:term-ch-b9-tobioriru) aggiunge il salto.

:::example_sentence
jp: >-
  {{船|ふね}}から{{飛|と}}び{{降|お}}りる。
translation_it: >-
  Salto giù dalla nave.
:::

#### ⚖️ Contrasto operativo

`{{船|ふね}}を{{降|お}}りる` può essere una discesa normale. `{{船|ふね}}から
{{飛|と}}び{{降|お}}りる` contiene un salto e un rischio maggiore.

[{{何|なん}}とか](term:term-ch-b9-nantoka) segnala una soluzione arrangiata:

:::example_sentence
jp: >-
  {{何|なん}}とか{{逃|に}}げる。
translation_it: >-
  Riesco in qualche modo a scappare.
:::

Quando la scena si chiude senza dire tutto, [また{{明日|あした}}](term:term-ch-b9-mata-ashita)
fa sparire il "ci vediamo":

:::example_sentence
jp: >-
  また{{明日|あした}}。
translation_it: >-
  A domani.
:::

:::

:::

jp: >-
  {{船|ふね}}から{{飛|と}}び{{降|お}}りて、{{何|なん}}とか{{逃|に}}げる。
translation_it: >-
  Salto giù dalla nave e riesco in qualche modo a scappare.
:::
