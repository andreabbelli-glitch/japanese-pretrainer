# Pitch accent data

`kanjium-accents.txt` is a local snapshot of Kanjium's raw pitch accent data:

https://github.com/mifunetoshiro/kanjium/blob/master/data/source_files/raw/accents.txt

additions or modifications to EDICT, KANJIDIC or KRADFILE were provided by Uros
O. through his free database."

Keep this file as an unmodified upstream snapshot. If it is refreshed, update
this README only if the upstream source or license text changes.
